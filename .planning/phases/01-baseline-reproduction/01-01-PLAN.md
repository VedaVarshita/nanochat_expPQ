**Step 4: Verify ENV-03 (PYTORCH_ALLOC_CONF)**
```bash

```

**Step 5: Download dataset (TOK-01)**
```bash
python -m nanochat.dataset -n 8
```
This downloads ~2B chars from HuggingFace. Takes ~2-5 minutes depending on network speed. Do not interrupt.

**Step 6: Train tokenizer (TOK-02)**
```bash
python -m scripts.tok_train --max-chars=2000000000
```
Saves tokenizer checkpoint to `~/.cache/nanochat/`. Takes ~34 seconds.

**Step 7: Evaluate tokenizer (TOK-03)**
```bash
python -m scripts.tok_eval
```
Must run without error and print vocab coverage statistics.

**Step 8: Record tokenizer checkpoint hash (TOK-04)**
```bash
sha256sum ~/.cache/nanochat/tokenizer.model 2>/dev/null || shasum -a 256 ~/.cache/nanochat/tokenizer.model
```
Save this hash value — it will be recorded in BASELINE.md in Plan 04. The tokenizer checkpoint must never be retrained; all subsequent runs reuse this exact checkpoint.
